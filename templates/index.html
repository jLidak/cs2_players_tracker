About the App

CS2 Player Tracker is an advanced web application designed to collect, process, and analyze the performance of Counter-Strike 2 players across various custom tournaments.

It allows administrators to create tournaments, set up bracket types, manage teams, and input detailed round-by-round statistics to see who truly dominates the server.

How is the Ranking Calculated?

The mathematical model for the ranking ensures a fair assessment of skill and consistency. The formula dynamically adjusts based on:

  • HLTV Rating 2.0: The core metric. Values above 1.0 reward points, while values below penalize the player.
  • Phase Bonuses: Reaching deeper stages of a tournament (Semi-finals, Finals) grants automatic rating boosts.
  • Rounds Root: The total number of rounds played acts as a non-linear multiplier, rewarding longevity without breaking the scale.
  • Tournament Weight: Each tournament can be individually weighted to reflect its prestige or difficulty.
